# YOUSEF.DEV — راهنمای آپلود نسخه بدون پوشه

این بسته برای آپلود از طریق صفحه وب GitHub آماده شده است؛ همه فایل‌های سایت در یک سطح قرار دارند تا نیازی به آپلود پوشه نباشد.

## فایل‌ها

- `index.html` — صفحه اصلی فارسی با امکان تغییر زبان داخل صفحه
- `english.html` — ورودی مستقل انگلیسی
- `hero-3d.webp` — تصویر پس‌زمینه مشترک
- `.nojekyll` — تنظیم کمکی GitHub Pages
- `README.md` و `README-FA.md` — راهنماها

## آپلود در GitHub

1. مخزن `youseftaghizadehdeveloper-pro.github.io` را باز کن.
2. اگر در ریشه فایل `index.html` فعلی هست، آن را با نسخه داخل این بسته جایگزین کن.
3. از `Add file` → `Upload files` استفاده کن و فایل‌های داخل بسته را به ریشه مخزن اضافه کن. اگر انتخاب‌گر فایل فایل‌های مخفی را نشان نمی‌دهد، نبودن `.nojekyll` برای این سایت استاتیک معمولاً مانع انتشار HTML/CSS/JS نمی‌شود.
4. در پایین صفحه `Commit changes` را بزن.
