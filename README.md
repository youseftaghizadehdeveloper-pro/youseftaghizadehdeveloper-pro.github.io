# YOUSEF.DEV — Flat Upload Edition

This package keeps all website files at the repository root, so you can upload individual files through GitHub's web interface without uploading folders.

## Files

- `index.html` — Persian home page with an in-page language toggle
- `english.html` — standalone English entry page
- `hero-3d.webp` — shared hero background image
- `.nojekyll` — helper file for GitHub Pages
- `README.md` and `README-FA.md` — publishing guides

## Publish

1. Open `youseftaghizadehdeveloper-pro.github.io` on GitHub.
2. Replace the existing root `index.html` with this package's `index.html`.
3. Use **Add file → Upload files** to upload the files from this package into the repository root.
4. Click **Commit changes**.
